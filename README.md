# To-Do Web App

A small beginner-friendly web application built with HTML, CSS, and JavaScript.

## Features

- Add tasks
- Mark tasks as completed
- Delete tasks
- Keep tasks after refreshing with browser local storage
- Responsive layout for desktop and mobile

## Run the project

Open `index.html` in a web browser. No installation is required.

## Put it on GitHub

```bash
git clone https://github.com/ChingChangTT/webApp.git
cd webApp
```

Copy the project files into that folder, then run:

```bash
git add .
git commit -m "Add simple to-do web app"
git push origin main
```
